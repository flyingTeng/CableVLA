# CableVLA

**面向线缆布线的仿真特权监督全局–局部表征学习**

[English](../README.md)

CableVLA 是面向机器人线缆布线的多模态视觉–语言–动作框架。它利用仿真特权监督学习全局线缆拓扑与局部触觉表征，结合视觉上下文和接触反馈，引导机器人完成线缆操作。

- **CableVLA**：结合拓扑条件化的动作生成与接触门控的力–触觉动作修正，实现机器人线缆布线。
- **TopoHead**：通过特权物理监督与教师–学生蒸馏学习时序线缆拓扑表征，从视觉观测中提取全局上下文。
- **TacSense**：通过双分支触觉编码器，联合建模阵列整体的时序变化与触觉单元的局部动态，学习接触、载荷和滑移表征。
